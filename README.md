# FiveM Phone System

A comprehensive phone system for FiveM using ESX Legacy and ox_inventory. This system includes messaging, contacts, and calling features, providing a complete in-game communication solution.

## Features

- **Messaging**: Send and receive messages in-game.
- **Contacts**: Add and manage contacts.
- **Calling**: Initiate and receive calls.

## Requirements

- FiveM server
- ESX Legacy
- ox_inventory

## Installation

1. Download the script.
2. Place the script in your FiveM resources folder.
3. Add `start PhoneSystem` to your server.cfg.
4. Run the provided SQL script to set up the database tables.

## Usage

- Use the phone item to open the phone UI.
- Navigate through the menus to send messages, add contacts, and make calls.

## Configuration

Configure the script by editing the `config.lua` file. You can set the phone item name, phone number length, and database table names.
